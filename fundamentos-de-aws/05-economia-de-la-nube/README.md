# Economía de la nube: CapEx vs OpEx, TCO

## CapEx vs OpEx

| | **CapEx** (gasto de capital) | **OpEx** (gasto operativo) |
| --- | --- | --- |
| Cómo se paga | Inversión grande al inicio | Pago recurrente por uso |
| Ejemplo | Comprar servidores | La factura mensual de AWS |
| Riesgo | Comprar de más o de menos | Gastar de más si no controlás |
| Típico de | On-premises | Cloud |

## TCO (costo total de propiedad)
Todo lo que cuesta tener algo funcionando, no solo el precio de lista.

On-premises incluye: hardware, licencias, energía, refrigeración, espacio, red, personal, mantenimiento, renovación.
Cloud incluye: lo que consumís, transferencia de datos, soporte, personal que lo opera.

## Para ahorrar en AWS
- Apagar lo que no se usa.
- Elegir el tamaño justo (*rightsizing*).
- Compromisos de uso (Savings Plans, instancias reservadas) para cargas estables.
- Presupuestos y alertas de costos desde el día uno.

**Idea clave:** pasar de CapEx a OpEx no garantiza ahorro. Hay que comparar con TCO.
